# Legacy Source Archive

This directory contains superseded implementation generations and historical source material retained for auditability and migration work.

It is **not part of the active runtime**. The public web root must point at `public/`, and `archive/.htaccess` denies web access to this tree if the repository root is accidentally exposed.

Archived material includes V7-V12 browser clients/APIs/descriptors/tests, superseded V10 cryptographic helpers, historical release files, and migration-era server components.
